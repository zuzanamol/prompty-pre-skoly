# Prompty pre školy

Vitaj v zbierke promptov pre učiteľov a školy. Nájdeš tu jednoduché zadania, ktoré môžeš vložiť do Microsoft Copilota a upraviť podľa svojej triedy.

## Ako použiť prompt

1. Vyber si prompt podľa nástroja, ktorý používaš.
2. Skopíruj text v časti **Prompt**.
3. Vlož ho do Copilota v príslušnom nástroji.
4. Doplň alebo uprav údaje tak, aby prompt sedel na tvoju triedu, predmet a cieľ.
5. Výsledok si skontroluj a uprav podľa svojich potrieb.
