# Prompty pre školy

Vitajte v zbierke promptov pre učiteľov a školy. Nájdete tu jednoduché zadania, ktoré vám pomôžu pripraviť materiály na vyučovanie pomocou nástrojov Microsoft 365 Copilot, ChatGPT alebo Gemini.

## Ako použiť prompt

1. Vyberte si prompt podľa nástroja a toho, čo potrebujete pripraviť.
2. Skopírujte text v časti **Prompt**.
3. Vložte ho do Copilota.
4. Upravte ho podľa svojich žiakov, predmetu a cieľa hodiny. Ak výsledok nie je presne podľa vašich predstáv, doplňte ďalšie pokyny.

Pred použitím si výsledok skontrolujte a prispôsobte. Do promptov nevkladajte osobné ani citlivé údaje o žiakoch.
